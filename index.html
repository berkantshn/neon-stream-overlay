Add it to OBS

  1. Copy the link above. Turn Demo mode off first and enter your channel.
  2. In OBS: Sources, +, Browser, Create new.
  3. Paste the link into URL. Set width 450 and height 800.
  4. Leave the custom CSS as it is. The background stays transparent.
